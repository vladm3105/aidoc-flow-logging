# Changelog

## Draft v1.3 — 2026-08-03

- Added `ualf-trace/v1.1` with portable tenant scope, agent/session identity,
  producer clock domains, observation time, terminal call statuses, explicit
  unavailable measurements, file/state lifecycle operations, and multi-agent
  events.
- Added `ualf-dataset/v1.2` with capture, amendment-cutoff, retention,
  revocation, external-dependency, signed qualification-evidence, and
  machine-readable datasheet bindings.
- Added signed rights, hygiene, replay, capture, retention, and erasure schemas.
- Added near-duplicate, benchmark-contamination, and split-leakage declarations.
- Added conformance classes, profile governance, contribution/IPR guidance, and
  security reporting.
- Updated OpenTelemetry GenAI targeting to the separate immutable upstream
  repository revision.

Historical `ualf-trace/v1` and `ualf-dataset/v1.1` identifiers are unchanged.
