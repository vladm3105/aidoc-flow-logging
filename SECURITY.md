# Security Policy

Do not open a public issue for a vulnerability that could expose retained
content, bypass artifact containment, forge qualification evidence, cross tenant
boundaries, or defeat integrity validation. Report it privately through GitHub's
security-advisory feature for this repository.

Include the affected profile and verifier version, a minimal synthetic proof of
concept, impact, and suggested mitigation. Do not include real secrets, personal
data, customer content, signing keys, or production artifacts.

Draft profiles receive best-effort fixes. A security correction that changes
accepted wire semantics receives a new profile identifier; historical artifacts
are not silently reinterpreted.
